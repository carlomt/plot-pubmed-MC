## Setup

Usa un virtualenv per isolare le dipendenze del progetto:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Per uscire dal virtualenv:

```bash
deactivate
```

## Uso

Con il virtualenv attivato:

```bash
python plot.py
```
